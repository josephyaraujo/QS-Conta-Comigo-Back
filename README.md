# QS Conta Comigo - Backend

Este repositório contém o backend do projeto Conta Comigo, responsável por fornecer a API e a lógica de negócio do sistema. Ele centraliza o processamento de dados, regras de negócios, autenticação e integrações necessárias para suportar as funcionalidades do aplicativo.

O objetivo principal foi realizar uma cópia do repositório do PDS para utilização dos arquivos para as atividades práticas da disciplina de Qualidade de Software.
